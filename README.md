# Gold Terminal

Торговый терминал по золоту (XAUUSD) для Windows. Работает через MetaTrader 5 вашего брокера.

## Скачать

**[⬇ Скачать последнюю версию](https://github.com/lety4ui/gold-terminal-releases/releases/latest)** — файл `GoldTerminal-<версия>.zip`.

## Установка

Нужен компьютер с Windows 10 или 11 (64-бит) и MetaTrader 5 от вашего брокера.

1. Распакуйте архив и запустите `GoldTerminal-Setup-<версия>.exe`.
2. Если Windows покажет синее окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
3. Нажимайте «Далее» до конца. Права администратора не нужны.
4. При первом запуске откроется мастер подключения — он по шагам поможет войти в счёт брокера.

Терминал запускается в учебном режиме PAPER: сделки виртуальные, реальные деньги не участвуют, пока вы сами не включите реальную торговлю.

## Обновление

В терминале: кнопка с номером версии вверху → «Проверить обновления». Счета, настройки и история сохраняются.
